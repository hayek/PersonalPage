Hit your session limit? Try /limit-reset

Claude Code has a new command that clears your 5-hour session limit on the spot, so you don't have to sit out the rest of the window. Here's what it does, how to use it, and the catch.

September 14, 2026 · 3 min read

I built Usage for Claude to see these limits before you hit them →

What it does

Claude plans have two limits that matter here: a session limit that rolls over every 5 hours, and a weekly limit on top of it. Normally, once you hit the session limit you wait for the window to reset.

/limit-reset clears your current session limit right away, so you can keep working. You can't use it whenever you like: after a reset, Claude Code tells you when the next one becomes available.

It doesn't reset your weekly limit. You don't get extra usage. Everything you use after the reset still counts toward your weekly limit, so you're spending this week's budget sooner, not adding to it.

How to use it

  1. Update Claude Code so you have the latest version: 
    claude update
  2. When you hit your session limit, type the whole command and press Enter. It won't autocomplete when you type /, so don't wait for it to show up in the command list: 
    /limit-reset
  3. Read the reply. If it worked, you'll see something like: 
    Session limit reset · next reset available <date> · your weekly limit still applies
    Then carry on where you left off.

Not everyone has it

The command is still rolling out, and Anthropic hasn't documented it in the Claude Code release notes yet. That means:

  • It's hidden. It doesn't appear in the / command list, so you can't tell whether you have it until you run it.
  • Running it doesn't guarantee a reset. Some accounts get the reset. Others get “A session-limit reset isn't available right now.” Anthropic hasn't said who qualifies.
  • This could change. Since it's undocumented, how often you can use it, who gets it, and what it's called could all change without notice.

If it doesn't work for you, the usual options still apply: wait for the session window to reset, or check what to do when you hit a usage limit in the Claude Code docs.

Using it wisely

Because a reset uses up your weekly limit faster, check how much weekly limit you have left before you use one. If you have plenty left, a reset is a good way to keep going. If you're close to the weekly limit, a reset only gets you there sooner, and the weekly limit takes much longer to come back.

Usage for Claude shows both at once in your menu bar: session and weekly limits side by side, plus a prediction of whether you'll hit a limit at your current pace. Two notification rules are especially useful here:

  • Weekly usage above 80%, so you know when it's time to stop using resets.
  • Session limit resets, so if the command isn't available to you, you know the moment you can pick things back up.
